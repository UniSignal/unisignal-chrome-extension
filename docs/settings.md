# 频道、声音和字体

在 Chrome 中打开一个新标签页，再点击工具栏上的 UniSignal 图标，即可打开设置页。

## 选择频道

“频道配置”中的“聚合监控”默认启用，无法在这里取消。

连接成功后，你会看到可选频道列表。勾选想看的频道，再点击“保存设置”。可选频道默认未勾选；取消勾选并保存后，该频道的消息会在页面中隐藏。

如果显示“当前没有可选频道”，说明当前没有可供选择的频道。

## 设置通知声音

在“显示与声音”中：

- “新消息通知声音”：控制扩展是否为可显示的新消息播放声音，默认开启。
- “通知声音大小”：调整聚合监控提示音的音量，范围为 0%–100%，默认 50%。调整滑块会触发试听。

**可选频道使用 GMGN 推特监控的提示音配置**，包括提示音类型、开关和音量。如果聚合监控有声音、其他频道没有声音，请同时检查 GMGN 自身的推特监控声音设置。

重新打开页面时显示的旧消息，以及“已编辑”的消息，都不会触发新消息提示音。

## 调整字体

拖动“消息字体大小”滑块：向右放大，向左缩小。调整后点击“保存设置”，再回到 GMGN 查看效果。

## 保存更改

调整频道、声音或字体后，点击“保存设置”，看到“设置已保存”即表示保存完成。设置保存在当前浏览器本地。

“保存并连接”用于保存 Token；“保存设置”用于保存频道、声音和字体，两者分别操作。
