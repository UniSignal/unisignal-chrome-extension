# 常见问题

## 点击扩展图标，为什么没有打开设置？

在已加载扩展的 GMGN 页面，图标用于切换混排／悬浮模式。切换到非 GMGN 标签页，再点击图标即可打开设置。

## 一直处于“连接中”或“等待重连”怎么办？

1. 确认网络正常。
2. 确认填写的是机器人提供的完整 Access Token，并点击过“保存并连接”。
3. 点击“重新连接”，观察状态是否变为“已连接”。
4. 仍然失败时，联系 [@unisignal_relay_bot](https://t.me/unisignal_relay_bot) 核实 Token 和频道访问权限。

反馈问题时提供连接状态和发生时间，请勿公开 Token。

## 显示“已连接”，为什么 GMGN 中看不到消息？

1. 确认已在 GMGN 打开推特监控面板。
2. 刚安装或更新扩展时，刷新 GMGN 页面。
3. 如果要查看可选频道，确认已勾选该频道并点击“保存设置”。
4. 等待新消息。首次安装没有本地历史；扩展只恢复此前保存在本机的最近消息。
5. 确认 `chrome://extensions/` 中 UniSignal 处于启用状态。

## 新消息为什么没有声音？

- 打开扩展设置中的“新消息通知声音”，并点击“保存设置”。
- 聚合监控的“通知声音大小”应大于 0%。
- 可选频道还需要在 GMGN 中开启推特监控提示音，并设置可听见的音量。
- 检查标签页、浏览器和系统是否静音；浏览器限制自动播放时，先在页面中点击一次，再等待新消息。
- 编辑消息和恢复的历史消息本来就不会播放提示音。

## 为什么没有“Telegram 原消息”或 CA 入口？

这些入口会根据消息内容显示。消息没有可用的原文链接，或没有可识别的代币合约地址时，就不会出现对应按钮。

## 更新扩展后，页面行为没有变化怎么办？

先刷新 GMGN 页面。如果仍没有变化，关闭该标签页，再重新打开 GMGN 和推特监控面板。

具体步骤见[安装与更新说明](installation.md#更新扩展)。

## 为什么旧消息不见了？

扩展只保留最近 100 条消息，较旧消息请到 Telegram 查看。频道中已删除的消息也会在扩展收到通知后移除。卸载扩展或清除扩展数据，会清除当前浏览器中保存的消息。

## 换一台电脑后需要重新设置吗？

需要。Token 和频道、声音、字体偏好保存在当前浏览器本地，不会通过本扩展自动同步到其他设备。
