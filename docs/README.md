# UniSignal 使用教程

UniSignal Telegram Feed 将 UniSignal 频道消息带到 GMGN 页面，让你在查看推特监控时一起阅读 Telegram 推送，并打开消息中对应的代币页面。

你需要一台安装了 Chrome 浏览器的电脑，以及用于获取连接凭证的 Telegram 账号。

[从 Chrome 应用商店安装 UniSignal](https://chromewebstore.google.com/detail/unisignal-telegram-feed/hcbiofphajciknflaghdkneniajhjkgg)。首次使用时，按下面的步骤完成连接即可。

## 第一次使用

1. [安装扩展](installation.md)。
2. [获取连接凭证并连接](connection.md)：跟随 Telegram 机器人的提示，复制凭证并粘贴到扩展设置中。
3. [在 GMGN 中查看消息](messages.md)：打开推特监控面板，等待频道新消息。
4. 按需调整[频道、声音和字体](settings.md)。

遇到问题时，查看[常见问题](faq.md)。数据处理方式见[隐私政策](privacy.md)。
