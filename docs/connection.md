# 获取连接凭证并连接

Access Token 是连接 UniSignal 所需的凭证，下面简称 Token。首次使用时保存一次，之后扩展会使用已保存的 Token 连接。

## 获取连接凭证

1. 打开 Telegram 中的 [@unisignal_relay_bot](https://t.me/unisignal_relay_bot?start=token)。
2. 按机器人提示获取 Access Token。如果提示需要先加入频道，请先完成提示中的步骤。
3. 复制机器人提供的完整 Token。

Token 用于验证你的访问权限，请勿分享给他人，或放入公开截图。

## 打开设置页

1. 在 Chrome 中打开一个新标签页。
2. 点击工具栏中的 UniSignal 图标。
3. 确认打开的页面标题为“Telegram 推送设置”。

在已加载扩展的 GMGN 页面点击图标，会切换消息显示模式。需要改设置时，先切换到非 GMGN 标签页再点击。

## 保存并连接

1. 将 Token 粘贴到 **Access Token** 输入框。
2. 点击“保存并连接”。
3. 等待右上角状态变为“已连接”。
4. 点击“打开 GMGN”，或刷新已有的 GMGN 页面。
5. 打开 GMGN 的推特监控面板，等待频道新消息。

连接成功后可以关闭设置页。Token 会保存在当前浏览器中，下次使用时不用重复填写。

## 连接状态

| 状态 | 含义与操作 |
| --- | --- |
| 未连接 | 先检查是否填写并保存了 Token。 |
| 连接中 | 正在连接，请稍等。 |
| 已连接 | 已准备好接收消息，可以打开 GMGN 查看。 |
| 等待重连 | 连接断开后正在等待自动重试，也可以点击“重新连接”。 |

持续无法连接时，查看[连接排查](faq.md)。
