# 安装扩展

请使用电脑上的 Chrome 浏览器（116 或以上版本）。

## 添加到 Chrome

1. 打开 [UniSignal Telegram Feed 商店页面](https://chromewebstore.google.com/detail/unisignal-telegram-feed/hcbiofphajciknflaghdkneniajhjkgg)。
2. 点击“添加至 Chrome”，在弹出的窗口中确认“添加扩展程序”。
3. 等待 Chrome 提示安装完成。

## 把图标固定到工具栏

1. 点击 Chrome 右上角的拼图图标，打开扩展菜单。
2. 找到 **UniSignal Telegram Feed**，点击旁边的图钉。
3. 工具栏上出现 UniSignal 图标后，就可以直接点击它了。

接下来[获取连接凭证并连接](connection.md)。如果已经打开 GMGN，请在连接完成后刷新页面。

## 更新扩展

通过商店安装后，Chrome 会自动更新扩展，通常不需要手动操作。

更新后刷新 GMGN 页面，再打开推特监控面板即可。遇到问题时，查看[常见问题](faq.md)。
